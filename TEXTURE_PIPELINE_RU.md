# Текущий стандарт terrain-текстур — Первый круг

Статус: **зафиксировано 01.09.2026**.

## Используемый файл

`assets/tiles/hell-terrain-current.png`

Используется прозрачный вариант, предоставленный пользователем. Все прежние terrain PNG из `assets/tiles/` удалены.

## Структура spritesheet

- 4 строки — биомы: земля, трава, камень, вода.
- 4 столбца — стороны: 0°, 90°, 180°, 270°.
- Каждый исходный тайл — логический canvas 32×32 px.
- Видимая игровая поверхность — изометрический тайл 32×20 px.
- Верхняя полупрозрачная точка остаётся частью исходного canvas и сохраняет высоту 32 px.
- Прозрачность за пределами тайла обязательна.

## Правило рендера

- Геометрия игрового тайла остаётся 2:1.
- Исходный пиксельный тайл увеличивается целочисленно ×4 до 128×80 px по поверхности.
- Полный 32×32 sprite-canvas становится 128×128 px.
- Спрайт привязан **нижней точкой** к математической точке клетки.
- Полные canvas соседних тайлов могут перекрываться, а порядок отрисовки определяется экранной глубиной.
- При повороте камеры биом не меняется: выбирается только соответствующий столбец 0/90/180/270.
- Сглаживание canvas отключено.
