# Исправление terrain-текстур: чёрные полосы и наложения

## Причина
Исходный прозрачный лист пользователя имеет размер 133×133 px: между соседними логическими ячейками 32×32 присутствуют 1-пиксельные чёрные разделители. Предыдущая версия рендера ошибочно считала размер ячейки 33×33 и вместе с terrain-тайлом отрисовывала эти разделители.

Это создавало чёрную сетку/полосы, особенно заметную при приближении.

## Исправление
- atlas очищен и нормализован до 128×128 px;
- теперь это ровно 4×4 ячейки по 32×32 px;
- в runtime больше не используется 33px pitch;
- destination-координаты и размеры больше не округляются по каждому тайлу отдельно, чтобы при дробном zoom соседние тайлы не расходились или не "наезжали" из-за разных округлений;
- сохраняется прозрачность и нижняя привязка полного 32×32 canvas;
- старые terrain-файлы не возвращались.

## Геометрия
Логическая поверхность: 32×20 px.
Полный canvas спрайта: 32×32 px.
Полная высота canvas остаётся визуально привязанной к нижней точке тайла.
