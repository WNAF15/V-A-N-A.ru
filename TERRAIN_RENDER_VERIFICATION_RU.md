# Проверка terrain-рендера

Проверены три уровня масштаба: 0.20×, 1.00× и 1.70×.

Проверка геометрии:
- source atlas: 128×128 px;
- 4×4 ячейки по 32×32 px;
- логическая поверхность тайла: 32×20 px;
- базовый игровой размер поверхности: 128×80 px;
- полный sprite canvas: 128×128 px;
- привязка: нижняя точка sprite canvas к экранной глубине тайла.

Исправления:
- удалены 1px чёрные разделители исходного 133×133 preview-atlas;
- runtime больше не читает 33×33 source-ячейки;
- отключено независимое округление destination-координат и размеров каждого тайла;
- прозрачность PNG сохранена;
- imageSmoothingEnabled=false сохраняет pixel-art без размытия.

Статические проверки:
- все JavaScript-файлы прошли `node --check`;
- atlas открылся как RGBA;
- atlas имеет размер 128×128;
- на границах x=32/64/96 не осталось непрозрачных чёрных разделителей;
- проведена визуальная симуляция изометрической сетки при zoom 0.20×, 1.00× и 1.70×.
