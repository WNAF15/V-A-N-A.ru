# Исправление terrain: исчезновение при zoom и техническая точка

## Исправлено

1. Удалены 16 одиночных технических пикселей из верхних углов ячеек terrain atlas.
   Они использовались только для искусственного размера исходного preview и не должны были попадать в рендер игры.
2. Canvas каждой ячейки сохранён 32×32 px, прозрачный фон сохранён.
3. Исправлен кэш глубины terrain: раньше он хранил экранные координаты, рассчитанные для старого zoom.
   Во время плавного изменения масштаба координаты устаревали, поэтому тайлы могли исчезать или возвращаться только после движения/поворота.
4. Теперь кэшируется только порядок отрисовки, а screen-координаты каждого тайла рассчитываются заново для текущего zoom на каждом кадре.

## Проверка

- atlas: 128×128 px;
- 4×4 ячейки по 32×32 px;
- технические маркеры: 0 непрозрачных пикселей в верхних углах ячеек;
- JavaScript: синтаксическая проверка всех .js файлов успешна.
